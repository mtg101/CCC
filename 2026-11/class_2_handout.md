# Introduction to Block Code
A 6-week course for students new to making computers do what they're told. 

## Class 2 - November 14th

### Title: Animations
Last class we makde Sprites react to things. Now we're going to make them move on their own!

### Course: https://projects.raspberrypi.org/en/projects/lost-in-space

### Goal: Complete the basic tutorial and learn how to animates Sprites in different ways

### How to ask for help
If you get stuck ask for help - and when you ask it helps if you tell us what you're trying to do, and what isn't working, like 'I'm clicking the drum but it doesn't make a noise' rather than just shouting 'it's broken it's broken'.

### Stretch Goals: more things you can do with this project, in class or later at home
- add another space object
    - what might be floating in space?
    - how would it move?
    - does it have other animations?
- add some space music
    - play space music while the scene animates
- guide a rocket
    - make a way to control where the rocket flies
    - keyboard controls? mouse?
    - does it interact with other objects if you guide it into them?
